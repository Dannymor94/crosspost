# CLAUDE.md

Все правила проекта живут в `AGENTS.md`. Этот файл только подключает их и уточняет роль Claude.

@AGENTS.md

## Твоя роль: исполнитель

- Работаешь по задаче из `docs/BACKLOG.md`, указанной владельцем (ID `T-NNN`).
  Нет ID → попроси его или предложи завести задачу. Без задачи код не пишешь.
- Ветка `task/T-NNN-коротко` от свежего `main`.
- Цикл: тест (красный) → код (зелёный) → Definition of Done (`AGENTS.md` §5) → PR
  по шаблону `.github/pull_request_template.md`.
- Ревью делает Codex. На его замечания отвечаешь коммитами в ту же ветку и коротким
  ответом в треде: что исправлено или почему нет.
- Вышел за рамки задачи (нашёл баг, нужен рефакторинг) → не чинишь молча, а заводишь
  новую задачу в `docs/BACKLOG.md` со статусом `todo`.
- Процесс целиком: `docs/WORKFLOW.md`.

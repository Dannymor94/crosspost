# T-509 / UX-00 — интерактивный прототип

Открыть index.html локально в браузере (скачать raw-файл). Никакого сервера, установки, учётных данных или реальных публикаций. CSP запрещает сетевые подключения. Все данные синтетические, состояние только в памяти страницы; reload сбрасывает демонстрацию. Не вводите настоящие клиентские данные.

## Сценарии для владельца
1. Клиент → Создать пост → текст/медиа → выбрать цели → предпросмотр → на проверку.
2. Администратор → Модерация → детали → одобрить или отклонить с причиной.
3. Календарь → неделя/месяц/список → день → детали → изменить время/отмена.
4. Публикации → фильтр внимания → раскрыть частичный результат и SUBMITTED.
5. Ещё → выбрать ошибку чтения → Публикации → повтор чтения.
6. Администратор → Ещё → частичный результат/потеря ответа → новый пост «Сейчас» → результат; никаких повторов SUBMITTED.
7. Смена профиля, темы, viewport телефона и возврат в черновик.

Прототип не является доказательством backend security, идемпотентности, durable drafts, точного timezone, accessibility compliance или real-platform preview. Импорт — только маршрут/описание существующей функции; подключение — симуляция; медиа — только имя/тип или демо-элемент. Telegram отложен. План в PR #51, этот PR stacked на него. Утверждение макетов владельцем и независимая проверка остаются открытыми.

## R2 — изменения по скриншотам владельца
- Один логотип, компактная шапка, сворачиваемая desktop-навигация, SVG-иконки, уменьшенные отступы, кликабельные строки.
- Счётчики открывают фильтры; внимание = проблемные публикации + проблемные подключения текущего профиля. Карточки не растягиваются из-за соседнего блока.
- Неделя показывает сами события, статус, время и площадки; месяц — события/число событий, мобильная неделя — вертикальные дни. Фильтры платформ и статусов, создание на дату. Список остаётся доступным.
- Проверки Chromium 360/390/768/1440 и dark/light. Это тесты прототипа, не подтверждение работоспособности backend или реальных устройств.

- **Зависимость:** T-209 (удаление отключено), T-213 (понятна реальная картина orphan-каталогов).
- **Зачем:** T-209 отключила удаление как временное решение. T-214 возвращает его, но уже с правильными условиями, выведенными из данных T-213 и из накопленных ревью.
- **Что сделать:** реализовать чистку, удовлетворяющую всем шести условиям из трёх раундов ревью PR #15 (перенесены дословно, чтобы ничего не восстанавливать по памяти):
  1. **submitted-каналы** — медиа не удалять, пока хотя бы один канал публикации в `submitted`: попытка переотправки ещё возможна. Нарушение: executor финализировал пост (все каналы терминальны), удалил медиа, хотя один канал был `submitted`.
  2. **shared-каталоги** — медиа не удалять, пока другой `scheduled_post` того же профиля ссылается на тот же каталог. Нарушение: Яндекс восстанавливает из checkpoint, создавая новую публикацию с тем же каталогом; отмена исходного поста удаляла медиа под активным checkpoint.
  3. **orphan после hard-DELETE** — `cancel_scheduled` делает hard-DELETE строки `scheduled_posts`; после этого `media_paths` теряется и TTL-sweep не может найти медиа submitted-постов, отменённых оператором.
  4. **корректная метка времени** — `updated_at` не обновляется raw SQL `INSERT … ON CONFLICT DO UPDATE` (только при INSERT через `server_default`); TTL, считающий от `updated_at`, удаляет медиа, у которого с момента SUBMITTED прошло меньше порога. Нужен явный `submitted_at`.
  5. **ретраемый FAILED во веб-контексте** — в веб-ретрае `failed` означает «ещё можно повторить вручную» (нет потолка попыток у пользователя); в executor `failed` терминален (исчерпан `max_attempts`). Одно условие удаления для обоих контекстов неверно.
  6. **замена медиа при PATCH с submitted-каналом** — `update_scheduled` скачивает новое медиа и перезаписывает `media_paths`; старый media-каталог теряется (orphan навсегда), если хотя бы один канал был `submitted`.
- **Готово, когда:** все шесть условий покрыты тестами (mutation-killing); TTL-sweep запускается из `run_once`; отчёт T-213 на тестовых данных не показывает необъяснимых orphan.

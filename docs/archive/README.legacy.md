# crosspost

Локальный кросс-постинг: загрузил контент → выбрал каналы → опубликовалось во все разом → видишь поканальный результат. Для себя и небольшого круга (3–5 человек). Ориентир — каналы, работающие в РФ; без зависимости от заблокированных облаков.

Контент **готовый, на входе.** Система доставляет, а не генерирует.

## Каналы

**API-тир** (надёжный): Telegram (Telethon), ВКонтакте, YouTube, Telegraph.
**Браузерный тир** (хрупкий, Playwright): WhatsApp, Instagram, Дзен, Яндекс Бизнес.

Граница API↔браузер — главный архитектурный принцип; от неё зависят релогин, IP, прокси и масштабирование. Подробно — в `PROJECT_GUIDE.md`.

## Запуск

```bash
uv sync                           # установить зависимости
uv run pytest                     # запустить тесты (моки, без ключей)
cp .env.example runtime/.env      # заполнить ключи (см. SETUP.md)
uv run python -m crosspost.web --reload   # dev-сервер с авто-перезагрузкой
```

**Важно**: всегда запускать с `--reload` в разработке. Без него изменения в Python-файлах не подхватываются, пока процесс не перезапустить вручную. Если запросы возвращают 404 или старое поведение — проверить, что сервер поднят с `--reload`, и перезапустить (`kill <pid> && uv run python -m crosspost.web --reload`).

Финальная проверка с реальными ключами: `make smoke`. Подробнее — в `SETUP.md`.

## Безопасность (важно)

Проект хранит токены и сессии (при друзьях — чужие аккаунты). Перед первым коммитом проверить, что `git status` не показывает `.env`, `runtime/`, `*.session`, `vault*`. Репозиторий — приватный. Детали — в `PROJECT_STRUCTURE.md`.

## Статус

Веб-интерфейс работает. Рабочие каналы: Telegram (API), Яндекс Бизнес (браузер), ВКонтакте стена (браузер), ВКонтакте канал (браузер), Instagram (API), Telegraph (API).

Ключевые возможности:
- Подключение каналов через пошаговый мастер (wizard)
- Публикация из браузера с поканальным итогом и ретраем
- Планировщик: импорт контент-плана из Google Sheets, автоматическая публикация созревших постов
- Telegram: поддержка форум-топиков (поиск через picker или вставка ссылки `t.me/...`)
- Логи ошибок с захватом скриншотов браузерных сбоев (admin console)

```bash
uv run pytest    # все тесты — на моках, ключи не нужны
```
